# CS 3502 Section W03 Project Two

## Overview
this project aims to determine a CPU scheduling algorithm that is efficient to improve the system performance.<br/>
the algorithms that are contained by the project are:
- `First Come, First Serve (FCFS)`
- `Shortest Job First (SJF)`
- `Round Robin (RR)`
- `Priority`
- `Shortest Remaining Time First (SRTF)`
- `Highest Response Ratio Next (HRRN)`

## Environment
since the project is structured entirely by `C#` and `Windows Forms` library is implemented for the graphical user interface (GUI),
it is highly recommend to use [**Visual Studio**](https://visualstudio.microsoft.com/) on `Windows` or any relevant Virual Machine.

## Build the Project
to run the project, first a local repository for this project is required.
#### Through Terminal
```
git clone https://github.com/bkim50/CPU-Simulator-GUI.git
```

OR 

#### Through Visual Studio
open the **Visual Studio** > select **Clone a repository** > copy below link and paste it on **Repository location** > then click a button **Clone**
```
https://github.com/bkim50/CPU-Simulator-GUI.git
```

## Run the Project
once the local repository is created, open the repository folder through IDE (e.g. Visual Studio)
then compile `Program.cs`.
